# Portfolio website

Static site: `index.html` (portfolio) plus three demo client sites (`barber.html`, `dental.html`, `plumber.html`).

- Change your name and email in `config.js`.
- Hosted on Netlify. Every push to `main` redeploys automatically.
- The contact form on `index.html` uses Netlify Forms (submissions appear in Netlify under **Forms**; turn on email notifications there).
- Forms on the demo pages are demos only and never send anything.
